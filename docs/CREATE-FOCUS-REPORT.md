# 0.6.1 · 新建文档时收起设置窗口

2026-11-02，版本 0.6.1（build 19）。

## 问题与修改

用户反馈从 Finder 新建文档时，设置主界面也会出现。此前独立小窗口解决了附着表单问题，但系统重新打开回调仍无条件显示设置，同时外部动作没有收起此前已打开的设置窗口。

- 外部请求开始执行时，使用 `orderOut` 收起设置窗口，随后才显示独立创建或授权窗口。应用内引导动作不受此规则影响。
- 系统服务的格式/应用选择窗口采用相同处理。
- 系统重新打开回调同时检查待办、已领取请求和正在显示的动作对话框；任一存在时不显示设置。回调由应用自行处理，不再允许 AppKit 继续默认窗口重排。
- 明确的 `settings` URL 和菜单栏设置入口仍可打开设置；动作结束后的普通应用重开仍可进入设置。
- 增加不包含路径或文件名的窗口显示/收起日志，便于区分后台动作与主动打开设置。
