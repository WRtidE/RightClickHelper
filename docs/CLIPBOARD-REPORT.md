# 文本历史移植报告

> 原始证据仅保留在本地，不纳入 Git；本报告保留测试结论与适用范围，详见 [证据说明](./evidence/README.md)。

日期：2026-10-21。版本：0.5.0（最终构建 14）。安装位置：`~/Applications/RightClickHelper.app`。

## 实现范围

- 主应用中新增可关闭的文本历史服务、剪贴板设置页和菜单栏入口，不在 Finder 扩展进程内监听按键。
- 双击左 Shift 打开鼠标附近的浮动卡片，外观按用户要求对齐原项目：180 点宽、40 点卡片、5 点间隔、10 点内边距，高度随条数变化且最高 291 点。无标题栏、透明背景、圆角浅色卡片、悬停放大、淡入上移。鼠标下方留 12 点，空间不足时翻至上方，再约束到当前屏幕可见区域；尊重系统减少动态效果设置。
- 点击/Enter 选用、Esc/失焦关闭；空历史不弹紧凑面板。搜索、删除单条、清空通过设置中的“搜索与管理…”打开独立窗口。
- 0.5 秒检查剪贴板变更，只保存纯文本；100 条、每条 256 KiB、总计 4 MiB 上限，按完整内容去重并置顶。仅保存内存，重启不恢复。
- 暂停时保留已有历史，恢复后只记录新复制内容；关闭功能则停止监听并清空历史。
- 只监听事件，不吞键或读取输入文字。右 Shift、组合键、输入/鼠标打断、长按与超时均不应触发。两次完整短按后才打开，第三次不会重复触发。
- 自动粘贴默认关闭。打开面板时保存原应用，选用时复制并尝试恢复该应用，再等待焦点、修饰键和权限条件满足后发送 ⌘V。出现第三个前台应用、新的剪贴板内容、原应用退出或操作被取消时，不继续发送。
- 休眠、用户会话失活和安全输入模式期间暂停相应操作；休眠与会话状态分别跟踪，避免仅唤醒就误认为会话已恢复。未做真实锁屏/唤醒验收，不把所有锁屏行为列为保证。

没有新增网络、自动化 Apple Events、完全磁盘访问或非沙盒后台进程。Finder 的目录授权、菜单配置和请求流程不依赖这些新增功能的权限。

## 权限与使用

用户明确同意启用剪贴板读取、输入监控、辅助功能三项访问。本机剪贴板 API 已报告允许，未出现额外读取提示；输入监控由系统要求用户亲自完成触控 ID 验证，再退出重开应用。辅助功能通过系统设置 `+` 添加已安装副本。

本机系统设置里的名称为 `RightClickHelper.app`。输入监控允许全局识别快捷键；辅助功能仅用于用户选中历史后的可选粘贴。未经许可时保留复制能力，不自动弹出循环请求。

来源应用提供的敏感、临时、自动生成标记会在读取文本之前检查；这依赖来源正确标注，并不是识别所有秘密文本的内容检测。标记约定参考 [NSPasteboard conventions](https://nspasteboard.org/)。

## 来源与边界

参考用户提供的 `RightButtonExtension 源码目录`。沿用其文本轮询、内存历史、面板和粘贴返回思路，重写单侧 Shift 判定、权限状态、资源上限与原应用保护。完整 MIT 许可和版权声明保存在根目录及应用资源的 `ThirdPartyNotices.txt`。

本版本不包含图片/文件历史、跨重启持久化、同步或开机启动。自动粘贴不是对所有应用的承诺：目标必须支持常规 ⌘V。跨系统、Intel 实机、干净账户和发行签名仍在安装矩阵中待测。
