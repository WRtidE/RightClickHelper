## 每个环境执行相同流程

1. 记录系统版本、CPU、构建版本、签名身份；运行 `bash scripts/install-preflight.sh /绝对路径/RightClickHelper.app` 保存输出。
2. 全新账户中安装到 `~/Applications`，打开应用、启用自身扩展、添加一个专用空目录。不要迁入原账户的容器或书签。
3. 检查空白处、单个文件/文件夹、多选菜单；新建六种格式、复制路径。取消和同名编号均应正确。
4. ⌘Q 退出主应用，由 Finder 新建唤醒；重复提交不重复创建。
5. 停用自身扩展、退出主应用、覆盖安装、重新启用；目录、常用应用配置保留。
6. 在方便中断工作的时机注销/重新登录及重启，重复第 3–4 步。
7. 移动测试目录、刷新授权；目录不可用时有重新授权入口。测试只读、删除测试目录、拒绝重新授权后继续使用其他目录。
8. 记录实际目标路径、文件数量、错误文本及是否依赖重启 Finder。失败不勾选通过。
9. 修改菜单开关、顺序、模板及默认应用；重启后确认保留。完成引导，重新测试应重置测试会话。
10. 停用自身 Finder 扩展，测试四个系统服务；复制支持多选，新建仅文件夹，取消后可继续。主应用退出后重复服务冷启动，并在目标宿主核对输入类型过滤。
11. 启用文本历史，分别验证允许/拒绝剪贴板读取、输入监控、辅助功能。物理双击左 Shift 弹出紧凑卡片，右 Shift、组合键与长按不弹；在多显示器边缘检查定位。验证暂停、搜索、清空、退出后历史清空及开关保留。
12. 在可丢弃的文稿中分别验证仅复制和自动粘贴；切换到第三应用、改变剪贴板、撤销权限或关闭原应用时不可误粘贴。真实休眠/唤醒和不同宿主分别记录，不以事件发送成功代替文稿内容检查。

`scripts/install.sh` 会保留旧安装副本，拒绝覆盖其他应用、签名无效来源或仍在运行的自身进程。签名有效、注册成功、菜单出现、动作成功是四个分别验证的结果。

13. 在“通用”页开启/关闭开机启动，对照系统登录项；开启后退出重开并覆盖安装，确认状态保留。实际注销或重启后确认主应用运行但设置窗口未弹出，双 Shift 可在权限具备时使用；停用后再次登录确认不自启。
