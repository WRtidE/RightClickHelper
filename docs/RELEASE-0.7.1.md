# 右键助手 0.7.1 · Mac 测试版

新建 Office 与文本文件、复制路径、在当前目录打开 Git 终端，以及双击左 Shift 查看文本历史。

## 本次更新

- 新建文件时收起设置窗口，只显示操作小窗口；后台运行时不出现 Dock 运行图标。
- 终端入口命名为“在此打开 Git 终端”，使用系统 Terminal 和默认 Shell。
- 应用图标统一为点击指针图案，替换默认占位图标。
- 重整 README 和完整指南，提供无需编译的应用测试包。

## 下载与安装

下载附件 `RightClickHelper-0.7.1-macOS-arm64.zip`，解压后将 `RightClickHelper.app` 移到 `~/Applications`，双击打开，并按提示启用 Finder 扩展。包内附有中文安装与更新说明，无需安装 Xcode。

适用于 Apple Silicon（M 系列芯片），最低系统目标为 macOS 14。Intel Mac 不适用本次安装包。已有实机验证覆盖 macOS 26.5.2，其他系统及干净账户待验证。

**当前为 Apple Development 签名测试包，未完成 Developer ID 签名和 Apple 公证。其他 Mac 可能被系统安全检查阻止，尚不能视为面向所有 Mac 的正式即用版。**

更新时请先停用旧版 Finder 扩展、退出旧版应用，再替换同一安装位置的应用并重新启用扩展。文件夹授权、输入监控和可选自动粘贴权限仍需由用户按系统提示确认。
