右键助手 · RightClickHelper

此包适用于 Apple Silicon（M 系列芯片）Mac，最低系统目标为 macOS 14。
已在开发者的 Mac 上验证；其他系统版本与干净账户尚未完整验证。

首次安装
1. 解压 ZIP，将 RightClickHelper.app 移入当前用户的“应用程序”文件夹（~/Applications）。
   如果该文件夹不存在，可在个人文件夹中创建 Applications 文件夹。
2. 双击应用，点击“打开扩展设置”，在系统设置中启用 Finder 扩展。
3. 回到桌面或普通文件夹，在空白处右键，选择“右键助手”。
4. 首次新建文件时按提示授权目标目录。无需安装 Xcode 或单独安装运行环境。

更新已有版本
1. 在系统设置中停用旧版 Finder 扩展。
2. 打开右键助手设置，用 Command-Q 退出应用。
3. 用新版替换原安装位置的 RightClickHelper.app，保留一份旧版备份。
4. 打开新版，重新启用 Finder 扩展；如系统提示权限变化，请重新确认权限。
   保持同一安装路径，避免同时运行多份副本。若系统提示应用正在使用，请先完成退出。

可选功能
在“剪贴板”页启用文本历史，按提示允许剪贴板读取与输入监控。
启用自动粘贴还需要辅助功能权限。历史只保存在内存，退出应用后清空。
在“通用”页可开启登录后自动运行。

测试版签名说明
当前包使用 Apple Development 签名，尚未采用 Developer ID 签名及 Apple 公证。
因此不能保证从 GitHub 下载后在其他 Mac 上直接通过系统安全检查。
系统可能阻止启动；本包不提供关闭系统安全保护的脚本。
正式对外分发还需完成 Developer ID 签名、公证与干净账户验证。
