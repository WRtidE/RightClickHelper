在桌面或 Finder 文件夹里点一下右键，就能新建 Word、PPT、Excel，复制路径，或在当前目录打开终端。复制过的文字也能通过双击左 Shift 找回来，选中记录后可粘贴到正在使用的应用。

右键助手在本机处理文件与文本历史。新建时只显示文件名小窗口，主应用以后台模式运行，设置可通过右键菜单里的 **打开右键助手…** 进入。

## 功能一览

| 想做什么 | 使用方式 |
| --- | --- |
| 新建办公文档 | 选择 Word、PowerPoint 或 Excel，输入名称后创建 |
| 新建文本文件 | 支持 TXT、Markdown 和 JSON |
| 复制路径 | 复制完整路径、文件名或终端转义路径，支持多选 |
| 在项目里运行 Git | **在此打开 Git 终端**，自动进入目标目录 |
| 用熟悉的编辑器打开 | 添加常用应用，可指定支持文件夹的应用与默认选项 |
| 找回刚才复制的文字 | 双击左 Shift 打开紧凑文本历史卡片 |
| 调整右键菜单 | 开关动作、调整顺序、选择常用的新建格式 |
| 登录后自动运行 | 在 **通用** 页开启 **开机启动（登录后运行）** |

## 安装与启动

当前源码版本为 **0.7.1（build 23）**，使用 Apple Development 签名，当前不提供 Apple 公证版本。最低编译目标为 macOS 14，已有实机验证覆盖 macOS 26.5.2 / Apple Silicon，其他系统与芯片组合待验证。

### 下载应用包

适用于 **Apple Silicon（M 系列芯片）Mac，macOS 14 或更高版本**；本次安装包不支持 Intel Mac。可在苹果菜单 → **关于本机** 查看芯片与系统版本。使用应用无需安装 Xcode。

1. 打开 [v0.7.1 发布页](https://github.com/WRtidE/RightClickHelper/releases/tag/v0.7.1)，在 **Assets** 中下载 `RightClickHelper-0.7.1-macOS-arm64.zip`。不要下载 `Source code`，那是源码。
2. 双击 ZIP 解压，打开解压后的文件夹，找到 `RightClickHelper.app`。
3. 将应用移入自己的应用程序文件夹：在 Finder 按 **⇧⌘H** 打开个人文件夹，进入 `Applications`（可能显示为“应用程序”）；没有该文件夹时可新建一个名为 `Applications` 的文件夹。
4. 双击移入后的 `RightClickHelper.app`。如果系统阻止打开，按下一节操作。

仓库和发布页已公开，无需登录 GitHub 或申请访问权限即可下载。也可以接收所有者直接提供的原始 ZIP。

### 首次打开被 macOS 拦截怎么办

这是**未公证的开发签名测试包**。以下步骤适用于“无法验证开发者”“Apple 无法检查是否包含恶意软件”等来源验证提示。仅在确认文件来自本仓库或可信的仓库所有者，并愿意使用此测试版时继续。

1. 先双击应用一次，让系统显示拦截提示，然后关闭提示。
2. 打开苹果菜单 → **系统设置 → 隐私与安全性**，向下找到 **安全性** 区域。
3. 找到与 `RightClickHelper`（或“右键助手”）对应的已阻止提示，点击 **仍要打开**。
4. 如系统要求，使用 Touch ID 或输入这台 Mac 的管理员凭据进行确认；在后续确认框中点击 **打开**。
5. 系统会为此应用保存例外，之后通常可以直接双击启动。更新应用后若再次出现提示，重新确认下载来源并按上述步骤处理。

如果看不到“仍要打开”，可重新尝试双击应用，再回到该设置页查看。公司或学校管理的 Mac 可能限制此操作，请联系管理员。

如果提示的是**“将损坏你的电脑”“包含恶意软件”或“已损坏”**，不要把它当作普通的开发者验证提示：停止打开，重新从发布页下载，并将完整提示和 macOS 版本反馈给维护者。本说明不要求关闭 Gatekeeper、SIP，也不需要运行终端命令移除隔离标记。

操作依据：[Apple 官方说明：在 Mac 上安全地打开 App](https://support.apple.com/zh-cn/102445)。这一步只是针对该应用的本机允许操作，不等于通过 Apple 公证，也不能保证所有 Mac 都能运行。

### 打开后启用右键菜单

1. 在右键助手窗口点击 **打开扩展设置**，在系统设置中启用 `RightClickHelper` Finder 扩展。
2. 回到桌面或普通 Finder 文件夹，在空白处右键 → **右键助手**。
3. 首次新建文件时，按提示选择并授权目标文件夹。
4. 如需文本历史，在应用的 **剪贴板** 页启用，并按提示授权剪贴板读取与输入监控；自动粘贴另需辅助功能权限。这些是可选功能。

本机测试系统的扩展入口位于 **通用 → 登录项与扩展 → 文件提供程序**；不同 macOS 版本可能不同，优先使用应用内的 **打开扩展设置** 按钮。主应用采用后台运行模式，Dock 不显示运行图标；需要设置时可从 Finder 的 **右键助手 → 打开右键助手…** 进入。

更新安装的步骤见[应用安装说明](docs/INSTALL-APP.txt)。

### 从源码安装

从源码安装需要完整 Xcode、Command Line Tools，以及本机有效的 Apple Development 签名身份。在项目根目录运行以下命令。

```bash
bash scripts/configure-signing.sh
bash scripts/build.sh
bash scripts/install.sh
```

安装位置为当前用户的 `~/Applications/RightClickHelper.app`。签名脚本从本机证书读取 Team ID，并将配置保存在 Git 忽略的 `Config/Local.xcconfig` 中。

1. 打开 **右键助手**，点击 **打开扩展设置**。
2. 在系统设置里启用 `RightClickHelper` Finder 扩展。
3. 回到桌面或普通文件夹，在空白处右键，找到 **右键助手**。

本机测试系统将扩展开关列在 **通用 → 登录项与扩展 → 文件提供程序** 中。不同系统的入口可能有变化，优先使用应用内的设置按钮。

更新已有版本时，先在系统设置中停用扩展，并用 ⌘Q 退出右键助手，再构建、安装和重新启用扩展。安装脚本会校验签名并保存旧版本备份。详细步骤见[更新安装指南](docs/USER-GUIDE.md#更新安装)。

## 第一次新建文件

1. 在桌面或文件夹空白处右键，选择 **右键助手 → 新建文件**。
2. 选择需要的格式。首次操作该目录时，按提示选择并授权目标文件夹。
3. 在小窗口中输入名称，点击 **创建**。
4. Finder 会选中新文件，双击即可用关联的软件编辑。

| 文件类型 | 创建后的内容 |
| --- | --- |
| Word `.docx` | 空白文档 |
| PowerPoint `.pptx` | 一张 16∶9 空白幻灯片 |
| Excel `.xlsx` | 一个名为“工作表1”的空白工作表 |
| 文本 `.txt` / Markdown `.md` | 空白文本文件 |
| JSON `.json` | `{}` 和换行 |

同名文件会自动增加序号。Office 文件由应用内置模板创建，创建过程可离线完成。打开和编辑文档使用你电脑上关联的办公软件。

## 在项目里打开 Git 终端

在项目文件夹的空白处右键，选择 **右键助手 → 在此打开 Git 终端**。系统 Terminal 会使用你的默认 Shell，并进入当前目录。右键单个文件夹时进入所选文件夹，右键单个文件时进入它的父目录。

打开后可输入以下命令，查看仓库状态。

```bash
git status
```

配置好 GitHub 远端并提交更改后，即可在这个窗口运行 Git 推送命令。终端入口也适用于运行项目脚本和其他日常命令。

## 双击左 Shift，找回复制过的文字

1. 打开 **右键助手 → 剪贴板**，勾选 **启用文本历史**。
2. 按页面提示允许剪贴板读取与全局按键监听。
3. 复制文字后，快速按下并松开两次 **左 Shift**，鼠标附近会弹出历史卡片。
4. 点击一条记录或按 Enter 选用，再用 ⌘V 粘贴。按 Esc 或点击面板外部可关闭。
5. 需要选中即粘贴时，开启 **自动粘贴回原应用（可选）**，并允许辅助功能权限。

历史最多保存 **100 条**，重复文字会移到最前。内容保存在内存中，退出应用或停用功能后清空。可在 **搜索与管理…** 中搜索、删除记录，也可暂停记录。

启用文本历史后，菜单栏会显示点击指针图标。关闭设置窗口后仍可使用快捷键，⌘Q 会退出整个应用。来源应用标记为敏感或临时的文本会被跳过，未标记的敏感内容仍可能被记录。

## 权限与使用范围

| 功能 | 需要的设置或权限 |
| --- | --- |
| Finder 右键入口 | 启用 Finder 扩展 |
| 新建文件、打开终端与常用应用 | 首次授权目标目录，之后复用保存的授权 |
| 双击左 Shift | 启用文本历史并允许输入监控 |
| 自动粘贴 | 额外允许辅助功能 |
| 登录后运行 | 在通用页开启开机启动，状态由系统登录项管理 |

右键入口覆盖桌面、普通 Finder 文件夹和适用的侧栏位置。搜索结果空白处、网页和其他应用正文的菜单支持受宿主与目标类型限制。多选文件时提供复制操作，打开终端与新建操作使用单个适用目标。

文件菜单默认覆盖 Finder。你也可以在 **工作目录** 页调整覆盖范围、添加目录或重新授权。权限、服务入口和中断恢复的完整说明见[使用与开发指南](docs/USER-GUIDE.md)。

## 常见问题

**右键里找不到助手？**

打开设置检查 Finder 扩展状态与菜单覆盖范围。可从 **诊断** 页查看最近记录，再到普通本地文件夹试一次。

**关掉设置后，助手还在运行吗？**

会继续在后台运行。主动打开设置使用右键菜单或文本历史启用后的菜单栏入口，退出整个应用使用 ⌘Q。

**为什么新建时要求选文件夹？**

首次使用需要授权当前目标目录。授权后会记住该目录，同名文件采用自动编号。

**双 Shift 没反应？**

确认主应用正在运行、文本历史已启用、输入监控已允许，并且已有文本记录。使用左 Shift 快速按两次。旧工具也启用相同快捷键时，关闭旧工具的监听。
